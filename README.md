# Interactive Quiz Web App

A clean, interactive quiz application featuring dynamic score calculation, instant answer feedback, and custom modern styling.

## Features
- **Dynamic Question Flow**: Seamless transitions between questions with instant state evaluation.
- **Score Tracking**: Real-time scoring calculation and final review screen.
- **Modern UI Styling**: Custom responsive layout with blue and gold accents.

## Tech Stack
- HTML5
- CSS3 (Responsive Flexbox/Grid)
- Vanilla JavaScript (DOM manipulation & event handling)

## How to Run Locally
Clone the repository and open `index.html` in any browser:

git clone [https://github.com/riyashevkani55-lgtm/quiz-app.git](https://github.com/riyashevkani55-lgtm/quiz-app.git)
